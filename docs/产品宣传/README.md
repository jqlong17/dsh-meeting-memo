# 产品宣传素材

对外分享用的图与话术。**所有截图都来自插件的「演示模式」，数据是虚构的**（虚构公司「云雀科技」、虚构产品「云雀文档 v2.4」、虚构人名），不含任何真实会议内容。

## 目录

```
原始素材/   插件面板的原始截图（今日 / 纪要 / 背景 / 转写服务 / 说话人识别）
成品/       合成的宣传图，1600×1000 逻辑尺寸，导出 2 倍图（3200×2000）
分享话术.md  可直接粘贴给他人 AI 的安装指令 + 一句话介绍 + 三条卖点
```

## 成品清单

| 文件 | 用途 |
| --- | --- |
| `01-封面.png` | 头图：产品名 + 一句话 + 三个卖点标签 |
| `02-本地录音与转写.png` | 功能图：时间轴、双轨采集、本地 JSONL |
| `03-AI纪要.png` | 功能图：背景/结论/TODO 四段成文 |
| `04-说话人识别.png` | 功能图：声纹与置信度 |
| `05-隐私与资源.png` | 功能图：Core ML 常驻内存、音频不出机器 |
| `06-安装.png` | 安装三步 + 包名 |

## 怎么重新生成

1. 在插件里打开「关于 → 演示模式」，把六个页面各截一张图，放进 `原始素材/`（保持文件名）。
2. 运行生成脚本（headless Chrome 渲染 HTML 再截图）：

```bash
python3 /tmp/make-cards.py     # 脚本不在仓库里，见下方说明
```

> 生成脚本是临时的（`/tmp/make-cards.py`），逻辑是「HTML 卡片 + headless Chrome 截图」。
> 如果要长期维护这些图，应把脚本移进 `scripts/`，本次先交付图片与话术。

## 注意

- 截图里出现的路径是 `/Users/demo/...`，不是真实用户名。
- 人名（苏晴 / 陈默 / 林知远 / 周叙）与公司均为编造，`tests/demo.test.ts` 里有禁用词断言防止误用真实内容。
